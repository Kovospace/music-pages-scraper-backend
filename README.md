# MusicPagesScraper

**MusicPagesScraper** is rewrite of [BandzoneScraper](https://github.com/K0V0/BandzoneScraper) 
into Java & Spring Boot with intention to make universal and easy extensible REST API for scraping content from webpages
and extracting useful data.



## Functions

Current version supports performing search and querying list of ***bands*** and it's ***band profile**s* with tracks.  
API performs database caching of results for some given time to dramatically increase speed and reduce processing power 
cost and bandwidth.  
Java version 8 or later and Spring Boot framework is required to compile.  
Live application runs on [https://music-pages-scraper.matejkovac.sk](https://music-pages-scraper.matejkovac.sk)

## Usage

Every endpoint is a plain `GET` and answers with `JSON` and a matching `HTTP` status code.
The API version is the first path segment — the current one is **v1** (`/v1/platforms`,
`/v1/{platform}/bands`, ...). Endpoints are versioned individually: a breaking change is published
as a new version of that one endpoint, the rest keep the version they already have.

The full API reference — endpoints, parameters, response schemas and error codes — is served by the
application itself as **OpenAPI 3** (generated by [springdoc-openapi](https://springdoc.org/)),
so there is no hand-written endpoint documentation here to fall out of sync with the code.
Open **Swagger UI** to browse it and fire test requests straight from the browser, no Postman needed:

| What | Live | Local |
|------|------|-------|
| Swagger UI | [`/swagger-ui.html`](https://music-pages-scraper.matejkovac.sk/swagger-ui.html) | `http://localhost:4000/swagger-ui.html` |
| OpenAPI spec, all versions (JSON) | [`/v3/api-docs`](https://music-pages-scraper.matejkovac.sk/v3/api-docs) | `http://localhost:4000/v3/api-docs` |
| OpenAPI spec, all versions (YAML) | [`/v3/api-docs.yaml`](https://music-pages-scraper.matejkovac.sk/v3/api-docs.yaml) | `http://localhost:4000/v3/api-docs.yaml` |
| OpenAPI spec, v1 only | [`/v3/api-docs/v1`](https://music-pages-scraper.matejkovac.sk/v3/api-docs/v1) | `http://localhost:4000/v3/api-docs/v1` |

Swagger UI has a dropdown to switch between API versions.
Each operation carries an `x-compatibility` extension in the spec saying which version it has been
stable since, whether it broke the previous one, and what replaces it — the same information is
rendered under **Compatibility** in the UI.

The spec can also be imported into Postman, Insomnia or any client generator.

Beyond the fields common to all platforms, individual platforms may enrich bands and tracks with
extra ones of their own (bandzone for instance adds `imageUrl`, `genre` and `city` to a band, and
`albumTitle`, `albumLabel` and `albumReleaseYear` to a track).
