MusicPagesScraper API

You have reached a backend server, not a website. It is a public REST API that searches bands and opens band profiles with their tracks on music sites, and hands them back as JSON for apps to use.

What it does

The music sites below have no API of their own. This server reads their pages, extracts the bands, profiles and tracks, and caches the results in a database for a while, so repeated questions are answered fast without loading the original site again.

  • Bandzone.cz – garage and underground bands from Czechia and Slovakia, mostly punk, rock and metal.
  • FreeTeknoMusic.org – tekno, tribecore, drum & bass and hardcore techno from the soundsystem and DIY scene.

Try it

Every endpoint is a plain GET answering in JSON, for example /v1/platforms or /v1/bandzone/bands?q=punk. All endpoints, parameters and response formats are documented interactively, and you can send test requests straight from the browser:
